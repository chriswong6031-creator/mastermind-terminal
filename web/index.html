Integrated Charting

Phase 0 harness

Lifted Lightweight Charts v5 engine rendering OHLC the charting container emits itself (web/ohlc/<T>.json). Same signal math (RSI / Stoch / MACD / Stoch RSI) the Pine confluence uses. Proves the render + data-contract path before live data is wired.

What this is. A standalone container (sibling of Mastermind) for a TradingView-lite charting system. This page is the Phase 0a render harness; the signal layer (signal_layer/) emits the mastermind.indicator/v1 and backtest_result/v1 contracts that Opus + the stock-picker consume. See docs/RESEARCH_AND_ARCHITECTURE.md.
Engine: TradingView Lightweight Charts v5 (Apache-2.0). Data shown is the macro repo's deep store (synthetic open) — for harness use only.
